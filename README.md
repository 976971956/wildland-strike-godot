# 荒野突击队（Godot 4）

一款可直接运行的原创像素风横版街机清关游戏。核心手感参考 90 年代街机 beat 'em up，采用高密度逐帧角色精灵、末世都市背景和原创合成音效。

## 在线体验

[打开 GitHub Pages 网页版](https://976971956.github.io/wildland-strike-godot/)

手机请横屏游玩：左侧虚拟摇杆移动，右侧 `A` 攻击、`B` 跳跃、`A+B` 释放耗血必杀，右上角暂停。触控会自动避开刘海/圆角安全区，可在设置中调整尺寸并切换经典、紧凑或左手布局；切到后台会自动暂停。电脑端继续支持键盘、可重绑定按键和手柄。

## 运行

1. 使用 Godot 4.3 或更高版本导入本目录的 `project.godot`。
2. 点击右上角运行项目，或在终端执行：`godot --path .`
3. 在标题画面按 Enter 或空格开始。

## 操作

| 动作 | 键盘 | 手柄 |
|---|---|---|
| 移动 | WASD / 方向键 | 左摇杆 |
| 攻击 / 连击 | J / Z | A / Cross |
| 跳跃 | K / X | B / Circle |
| 旋风技 | L / C | X / Square |
| 开始 | Enter / 空格 | Start |
| 暂停 / 设置 | Esc / P | Start（游戏中） |

本地合作支持 1–3 人：键盘固定为 P1，最多两只手柄在标题或选人画面按 Start 加入。每名玩家独立选择角色并确认，全部准备后才会进入关卡；手柄 Back 可取消准备或让该手柄玩家退出。队友倒地后，在八秒内靠近并按攻击可将其救起；超时则消耗该玩家自己的续关次数。两名附近队友在 0.24 秒内先后按旋风技可触发合体技，未成功联动时仍会正常释放各自的旋风技。

靠近小型敌人攻击可抓住对方，再按攻击即可投掷；靠近轮胎、油罐等小型场景物也可将其举起，再按攻击投向敌人。跳起后攻击会使出飞踢；旋风技会消耗少量生命。四档食物按角色补给效率恢复生命，四档贵重物提供不同分数。

第三关会自动登上沙漠拦截车：按右加速、按左制动、按上/下切换三条车道，攻击或旋风键均可操作车载机枪；高速撞击敌人会造成重伤，撞上路障、油污和首领地雷则会损失车体耐久。第四关深入装甲车库和铸造厂，传送带会改变站位，压力机与熔炉喷口按独立节奏预警并伤害任一阵营。第五关进入火灾中的聚落，火区、烟幕和高压水柱会改变安全路线，关底首领会从人形指挥官真正变身为灰烬巨兽。第六关穿过雨林研究道进入泰坦矿井，孢子云、失控矿车与巨兽踩踏会持续改变站位，矿区指挥官还能撕裂地面并呼叫巨型生物增援。第七关乘装甲货梯深入低温金库，移动甲板、安保激光和冷冻喷口会切割战场，关底需要同时击破会联动屏障与交叉火力的两名金库哨兵。第八关攻入基因锻造实验室，电弧场、诱变池与创世核心浪涌会持续压缩安全区域，最终首领会依次变为 Apex Mantle 与悬浮的 Genesis Core；通关后进入原创结局、制作人员字幕与八关战役报告。

- 刀兵佯攻突进、延时爆破、正面盾防/破盾恢复、精英击倒韧性与四套可复用遭遇配方
- 三段连击、跳击、抓投、清场技与双人合体技
- 十二种独立武器行为：重击、长鞭、电击、散射、连发、穿透、燃烧、火箭与地雷等
- 可破坏箱体、滚动危险物、可搬运/投掷场景物与分级补给掉落

## 自动检查

```sh
godot --headless --log-file /tmp/wildland-import.log --path . --import
godot --headless --log-file /tmp/wildland-tests.log --path . --script res://tests/test_runner.gd
```

全新的 clone 必须先执行 `--import` 生成 `.godot` 资源缓存。完整发布复现（导入、全测试、Web、iOS、可用时的 Xcode arm64 无签名构建）可直接运行：

```sh
./tools/verify_release.sh
```
