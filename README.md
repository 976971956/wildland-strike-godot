# 荒野突击队（Godot 4）

一款可直接运行的原创像素风横版街机清关游戏。核心手感参考 90 年代街机 beat 'em up，采用高密度逐帧角色精灵、末世都市背景和原创合成音效。

## 在线体验

[打开 GitHub Pages 网页版](https://976971956.github.io/wildland-strike-godot/)

手机请横屏游玩：左侧虚拟摇杆移动，右侧 `A` 攻击、`B` 跳跃、`SP` 释放耗血必杀。电脑端继续支持键盘和手柄。

## 运行

1. 使用 Godot 4.3 或更高版本导入本目录的 `project.godot`。
2. 点击右上角运行项目，或在终端执行：`godot --path .`
3. 在标题画面按 Enter 或空格开始。

## 操作

| 动作 | 键盘 | 手柄 |
|---|---|---|
| 移动 | WASD / 方向键 | 左摇杆 |
| 攻击 / 连击 | J / Z | A / Cross |
| 跳跃 | K / X | B / Circle |
| 旋风技 | L / C | X / Square |
| 开始 | Enter / 空格 | Start |

本地合作支持 1–3 人：键盘固定为 P1，最多两只手柄在标题或选人画面按 Start 加入。每名玩家独立选择角色并确认，全部准备后才会进入关卡；手柄 Back 可取消准备或让该手柄玩家退出。队友倒地后，在八秒内靠近并按攻击可将其救起；超时则消耗该玩家自己的续关次数。两名附近队友在 0.24 秒内先后按旋风技可触发合体技，未成功联动时仍会正常释放各自的旋风技。

靠近小型敌人攻击可抓住对方，再按攻击即可投掷。跳起后攻击会使出飞踢；旋风技会消耗少量生命。食物恢复生命，短刃可强化 12 次攻击。

## 内容

- 四段式推进关卡与锁屏战斗
- 普通兵、重装兵、迅猛龙、关底首领
- 三段连击、跳击、抓投、清场技
- 生命、残机、计分、Boss 血条、补给掉落
- 轻、中、重分级停帧，打击震屏、受击白闪与手机震动反馈
- 15 帧玩家动作表、12 帧人类敌人动作表与 4 帧迅猛龙动作表
- 1280×720 高密度都市废墟像素背景与原创合成街机音效
