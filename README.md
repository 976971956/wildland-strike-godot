# 荒野突击队（Godot 4）

一款可直接运行的原创像素风横版街机清关游戏。核心手感参考 90 年代街机 beat 'em up，采用高密度逐帧角色精灵、末世都市背景和原创合成音效。

## 在线体验

[打开 GitHub Pages 网页版](https://976971956.github.io/wildland-strike-godot/)

手机请横屏游玩：左侧虚拟摇杆移动，右侧 `A` 攻击、`B` 跳跃、`SP` 释放耗血必杀。电脑端继续支持键盘和手柄。

## 运行

1. 使用 Godot 4.3 或更高版本导入本目录的 `project.godot`。
2. 点击右上角运行项目，或在终端执行：`godot --path .`
3. 在标题画面按 Enter 或空格开始。

## 操作

| 动作 | 键盘 | 手柄 |
|---|---|---|
| 移动 | WASD / 方向键 | 左摇杆 |
| 攻击 / 连击 | J / Z | A / Cross |
| 跳跃 | K / X | B / Circle |
| 旋风技 | L / C | X / Square |
| 开始 | Enter / 空格 | Start |

本地合作支持 1–3 人：键盘固定为 P1，最多两只手柄在标题或选人画面按 Start 加入。每名玩家独立选择角色并确认，全部准备后才会进入关卡；手柄 Back 可取消准备或让该手柄玩家退出。队友倒地后，在八秒内靠近并按攻击可将其救起；超时则消耗该玩家自己的续关次数。两名附近队友在 0.24 秒内先后按旋风技可触发合体技，未成功联动时仍会正常释放各自的旋风技。

靠近小型敌人攻击可抓住对方，再按攻击即可投掷；靠近轮胎、油罐等小型场景物也可将其举起，再按攻击投向敌人。跳起后攻击会使出飞踢；旋风技会消耗少量生命。四档食物按角色补给效率恢复生命，四档贵重物提供不同分数。

第三关会自动登上沙漠拦截车：按右加速、按左制动、按上/下切换三条车道，攻击或旋风键均可操作车载机枪；高速撞击敌人会造成重伤，撞上路障、油污和首领地雷则会损失车体耐久。第四关深入装甲车库和铸造厂，传送带会改变站位，压力机与熔炉喷口按独立节奏预警并伤害任一阵营。第五关进入火灾中的聚落，火区、烟幕和高压水柱会改变安全路线，关底首领会从人形指挥官真正变身为灰烬巨兽。第六关穿过雨林研究道进入泰坦矿井，孢子云、失控矿车与巨兽踩踏会持续改变站位，矿区指挥官还能撕裂地面并呼叫巨型生物增援。

## 内容

- 六关连续战役：都市废区、洪水荒野、公路载具战、工业铸造厂、燃烧聚落与原始丛林矿区，共十八段独立场景、二十八组锁屏遭遇
- 六节点战役路线图、逐关威胁倍率、资源化时间/残机/通关奖励、跨关分数与残机保留，以及当前战役完成报告
- 六类标准敌人、四类系统化精英、四种生态恐龙与六名多阶段关底首领
- 刀兵佯攻突进、延时爆破、正面盾防/破盾恢复、精英击倒韧性与四套可复用遭遇配方
- 三段连击、跳击、抓投、清场技与双人合体技
- 十二种独立武器行为：重击、长鞭、电击、散射、连发、穿透、燃烧、火箭与地雷等
- 可破坏箱体、滚动危险物、可搬运/投掷场景物与分级补给掉落
- 中立恐龙跨阵营战斗，以及休眠、苏醒、低血激怒状态
- 三处双阵营水流危险、旅行潮汐波，以及跨关保留分数/残机/合作阵容
- 类型化共享载具：加减速、三车道转向、路障碰撞、冲撞伤害、三人独立车载射击、车体耐久与布雷/追撞首领
- 类型化工业机关：连续传送带、独立错相压力机与熔炉喷口，以及磁力牵引、双向炉火波和召援阶段组成的 Forge Regent 首领战
- 类型化灾害机关：循环火区、减速烟幕、双向高压水柱，以及双图集形态、火线、冲撞和水压爆发组成的 Cinder Matriarch 首领战
- 类型化丛林矿区机关：减速毒孢子、往返失控矿车、巨兽踩踏，以及连续地裂、巨兽召援和钻枪冲锋组成的 Titan Warden 首领战
- 生命、残机、计分、Boss 血条、四档食物与四档贵重物
- 轻、中、重分级停帧，打击震屏、受击白闪与手机震动反馈
- 四名英雄各 24 状态动作表，人类敌人与恐龙各使用独立 8 状态动作表
- 1280×720 高密度都市废墟、季风荒野、瀑布遗迹、峡谷公路、雷暴高架、装甲车库、熔炉核心、史前雨林与地下化石矿井背景，以及原创合成街机音效
