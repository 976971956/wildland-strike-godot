# Wildland Strike project instructions

For every task that changes this repository, use the project skill at `.agents/skills/wildland-strike-arcade/SKILL.md`.

Before implementation, read `PROJECT_PLAN.md` and select work from its next-task queue unless the user specifies another in-scope task. A completed mutation must include appropriate tests, a roadmap status update, a Git commit, and a push to `origin/main`. Rebuild and verify GitHub Pages for player-visible changes.

The public project is a clean-room, mechanically faithful arcade tribute. Do not add ROM-extracted assets, original game music/dialogue, licensed logos, original character names, or Cadillac branding.
